# Windows Update Pauser ⏳

Скрипт на Python для автоматического продления паузы обновлений Windows. Позволяет удерживать систему в состоянии приостановки обновлений без отключения системных служб.

## ⚙️ Как это работает

При каждом запуске скрипт берёт текущее время в UTC и время через 14 дней, после чего записывает их в реестр Windows по пути:

`HKLM\SOFTWARE\Microsoft\WindowsUpdate\UX\Settings`

Записываемые параметры (тип `REG_SZ`, формат `YYYY-MM-DDTHH:MM:SSZ`):

| Параметр | Значение |
|---|---|
| `PauseUpdatesStartTime` | текущее время |
| `PauseUpdatesExpiryTime` | текущее время + 14 дней |
| `PauseFeatureUpdatesStartTime` | текущее время |
| `PauseFeatureUpdatesEndTime` | текущее время + 14 дней |
| `PauseQualityUpdatesStartTime` | текущее время |
| `PauseQualityUpdatesEndTime` | текущее время + 14 дней |

Скрипт открывает 64-битную ветку реестра (флаг `KEY_WOW64_64KEY`) и создаёт раздел `Settings`, если его нет.

Задача в Планировщике запускает программу ежедневно и при каждом старте системы, поэтому дедлайн паузы всегда отодвинут почти на полные 14 дней. Даже если компьютер несколько дней был выключен, пауза продлится при следующем включении.

Программа работает без окон. Результат каждого запуска записывается в лог:

`C:\ProgramData\PostponeWinUpdate\log.txt`

## 🚀 Требования

* Windows 10 / 11 x64
* Python 3.9+ (только для сборки)
* Права администратора (для установки)

## 📁 Структура проекта

* `main.py` — основной скрипт, продлевающий паузу в реестре.
* `install_task.bat` — установщик: копирует программу и регистрирует задачу в Планировщике.
* `uninstall_task.bat` — полное удаление: задача, программа, логи и параметры паузы в реестре.
* `.gitignore` — исключения для Git (кэш, файлы `*.spec`, папки сборки и виртуального окружения).
* `README.md` — документация проекта.

## 📦 Сборка .exe

Скрипт компилируется в автономный исполняемый файл с помощью `PyInstaller`, чтобы не зависеть от установленного Python.

1. Установите сборщик в виртуальное окружение (`.venv`):
   ```bash
   pip install pyinstaller
   ```
2. Соберите проект:
   ```bash
   pyinstaller --clean --noconsole --onefile --uac-admin --name PostponeWinUpdate --distpath ./builds main.py
   ```

Готовый файл `PostponeWinUpdate.exe` появится в папке `builds/`.

Флаг `--clean` очищает кэш PyInstaller перед сборкой, чтобы в exe не попали устаревшие файлы от предыдущих сборок.

Во время сборки PyInstaller также создаёт папку `build/` с промежуточными файлами (байткод, списки зависимостей, отчёты `warn-*.txt` и `xref-*.html`). Для работы программы она не нужна: её можно удалить, при следующей сборке она создастся заново. Отчёт `warn-PostponeWinUpdate.txt` бывает полезен для отладки, если exe не запускается из-за отсутствующего модуля.

## 🛠️ Установка

1. Убедитесь, что `PostponeWinUpdate.exe` находится в папке `builds/`.
2. Нажмите правой кнопкой мыши на **`install_task.bat`**.
3. Выберите **«Запуск от имени администратора»**.

### Что делает установщик

* Проверяет права администратора и наличие собранного exe.
* Останавливает задачу, если она уже запущена (при переустановке).
* Копирует exe в `C:\Program Files\PostponeWinUpdate\`. Так задача не зависит от расположения папки проекта, а exe, который запускается от SYSTEM, лежит в защищённой от записи папке.
* Регистрирует в Планировщике задачу `Windows Update Pauser`:
  * запуск **ежедневно в 12:00** и **при каждом старте системы**;
  * **пропущенные запуски выполняются** при первой возможности (если ПК был выключен в момент срабатывания);
  * запуск от учётной записи **SYSTEM** с наивысшими правами: задача работает без входа пользователя и без запросов UAC;
  * запуск разрешён при работе от батареи, время выполнения ограничено 5 минутами.
* Сразу выполняет задачу один раз, чтобы пауза применилась немедленно.
* Выводит статус зарегистрированной задачи для проверки.

Повторный запуск `install_task.bat` безопасен: он обновит exe и перезапишет задачу. Используйте его после каждой пересборки.

## ✅ Проверка работы

* **Параметры → Центр обновления Windows**: должна отображаться пауза с датой окончания примерно через 14 дней.
* **Лог** `C:\ProgramData\PostponeWinUpdate\log.txt`: после каждого запуска появляется строка вида `INFO Пауза продлена до ...`. Ошибки записываются с полным текстом исключения.
* **Реестр**: значения из таблицы выше в разделе `HKLM\SOFTWARE\Microsoft\WindowsUpdate\UX\Settings`.
* **Планировщик заданий**: у задачи `Windows Update Pauser` видны время последнего запуска и результат (`0x0` — успешно).

## 🧹 Удаление

Нажмите правой кнопкой мыши на **`uninstall_task.bat`** и выберите **«Запуск от имени администратора»**. После подтверждения скрипт:

* остановит и удалит задачу `Windows Update Pauser` из Планировщика;
* удалит папку программы `C:\Program Files\PostponeWinUpdate\`;
* удалит логи из `C:\ProgramData\PostponeWinUpdate\`;
* удалит параметры паузы из реестра, после чего обновления возобновятся.

Если в **Параметрах → Центр обновления Windows** пауза всё ещё отображается, нажмите там **«Возобновить обновления»**.

## ⚠️ Ограничения

* Механизм паузы через реестр официально не документирован. Microsoft может изменить его поведение в будущих сборках Windows.
* Неподписанный exe, собранный PyInstaller и изменяющий реестр, может помечаться антивирусом (в том числе Защитником Windows) как подозрительный. При необходимости добавьте его в исключения.
* Задача не будит компьютер из сна и не включает его: продление произойдёт при следующем включении или пробуждении.
* Официальная альтернатива для редакций Pro и выше: политики отсрочки обновлений в `gpedit.msc` (**Конфигурация компьютера → Административные шаблоны → Компоненты Windows → Центр обновления Windows**). Они позволяют отложить исправления до 30 дней, а функциональные обновления до 365 дней, и не требуют периодического перезапуска.
