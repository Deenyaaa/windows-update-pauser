# Windows Update Pauser ⏳

Скрипт на Python для автоматического переноса (продления) паузы обновлений Windows. Позволяет удерживать операционную систему в состоянии приостановки обновлений без полного отключения системных служб.

## ⚙️ Как это работает
Каждый раз при запуске скрипт рассчитывает текущую дату и дату через 7 дней (в формате ISO 8601), а затем перезаписывает ключи в реестре Windows по пути:
`HKLM\SOFTWARE\Microsoft\WindowsUpdate\UX\Settings`

Это имитирует штатную кнопку «Приостановить обновления» в Центре обновлений Windows, постоянно сдвигая дедлайн вперед.

## 🛠️ Настройка автозапуска (Windows Task Scheduler)
Чтобы скрипт работал полностью в фоне и регулярно сдвигал дату, его лучше всего запустить через **Планировщик задач** от имени системы `СИСТЕМА (SYSTEM)`. При таком подходе консольное окно не будет всплывать на экране.

1. Откройте **Планировщик задач** (Task Scheduler).
2. Нажмите **Создать простую задачу** (Create Basic Task).
3. Задайте триггер: **Еженедельно** (выберите удобный день и время).
4. Действие: **Запуск программы** (Start a program).
5. Заполните поля запуска:
   * **Программа или скрипт:** Укажите путь к вашему `python.exe` (или `pythonw.exe`, чтобы скрыть окно).
   * **Добавить аргументы:** Имя вашего скрипта (например, `update_pauser.py`).
   * **Рабочая папка:** Полный путь к папке, где лежит скрипт.
6. **Важно:** После создания задачи откройте её свойства, на вкладке **«Общие»** найдите блок настроек пользователей и нажмите *«Изменить пользователя или группу»*. Введите **СИСТЕМА** (или **SYSTEM** в английской версии Windows) и примените изменения. Убедитесь, что стоит галочка **«Выполнять с наивысшими правами»**.
